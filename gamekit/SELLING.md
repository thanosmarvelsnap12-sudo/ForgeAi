# GameKit launch checklist

1. Publish the GitHub Pages storefront.
2. Add the finished downloadable files to `gamekit/downloads/`.
3. Choose a payment/digital-delivery provider whose terms allow the account holder's age and location.
4. Create one checkout product for each pack: $0.99, $2.99, and $4.99.
5. Put the provider checkout links into the storefront buttons.
6. Test every purchase/download flow before sharing the site.

Important: never bypass age, identity, payment, or platform rules. If an adult account holder is required, a parent/guardian must handle that part.
